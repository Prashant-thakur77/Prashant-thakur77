## ☀️ Google Summer of Code 2026 · Learning Equality

<img align="right" width="90" src="https://developers.google.com/open-source/gsoc/resources/downloads/GSoC-icon-192.png" />

**Project: `KMultiSelect`, an accessible multi-select dropdown for the [Kolibri Design System](https://github.com/learningequality/kolibri-design-system)**

Kolibri brings offline education to learners in low-resource communities around the world, so every component has to work for everyone.

- 🧱 Designed a **slot-based API** with composable architecture (`useMultiSelectList`, `useMultiSelectKeys`)
- ♿ Full **keyboard navigation** and **screen-reader support**, tested with **Orca** on Ubuntu, following WCAG
- 🔁 Iterated through mentor review on chip ordering and indeterminate-checkbox semantics
- ✅ Built a QA checklist for the `CategoryOptions` component
- 🙏 Mentored by Liana Harris, Radina Matic and Michaela Robosova

**Before and beyond GSoC:** **15+ merged PRs** to [`learningequality/studio`](https://github.com/learningequality/studio) for the **Vuetify-removal initiative**, covering `KDropdownMenu` slot forwarding, `StudioSideNavOption` keyboard navigation and `KSnackbar` composable design.
