## ☀️ Google Summer of Code 2026 · Learning Equality

Built **[`KMultiSelect`](https://github.com/learningequality/kolibri-design-system)**, an accessible multi-select for the Kolibri Design System, which powers offline education for learners worldwide.

- Composable, slot-based API (`useMultiSelectList`, `useMultiSelectKeys`)
- Full keyboard and screen-reader support, verified with Orca against WCAG
- Plus **15+ merged PRs** to [`studio`](https://github.com/learningequality/studio), helping remove Vuetify from the codebase
